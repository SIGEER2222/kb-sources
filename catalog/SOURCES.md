## Blizzard reference files

The full Blizzard Catalog XML library (UnitData, AbilData, WeaponData,
EffectData, BehaviorData, ActorData, UpgradeData, RequirementData, ButtonData,
ValidatorData, MoverData, TargetFindData, TargetSortData, TurretData,
FootprintData, TalentData, and ~30 more) is no longer mirrored in
`kb-sources/catalog/reference/`. It is indexed directly from the official data
mirror at `../sc2-data-trigger/` (git-ignored, 222 MB), under the `sc2-official`
source alias. See `../sc2-data-trigger/SOURCES.md` for the per-file inventory.

Files marked "Blizzard assets; reference only" are extracted from the official
StarCraft II 5.0.16.97364 data build. See `../SOURCES.md` for license summary.
