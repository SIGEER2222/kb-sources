## Blizzard reference files

The full Blizzard Galaxy reference library (natives.galaxy, NativeLib_h.galaxy,
natives_missing.galaxy, and the GameData/*.galaxy catalog headers: Abil, Actor,
Behavior, Effect, Unit, Upgrade, Weapon, etc.) is no longer mirrored in
`kb-sources/galaxy/natives/`. It is indexed directly from the official data mirror
at `../sc2-data-trigger/` (git-ignored, 222 MB), under the `sc2-official` source
alias. See `../sc2-data-trigger/SOURCES.md` for the per-file inventory.

Files marked "Blizzard assets; reference only" are extracted from the official
StarCraft II 5.0.16.97364 data build. See `../SOURCES.md` for license summary.
